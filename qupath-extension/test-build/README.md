# Test build

`qupath-extension-omero-annotate-ai-0.1.0.jar` is a build of this branch for trying
the extension out before there is a release. Drag it onto QuPath 0.6 or 0.7 and
restart QuPath (see [the guide](../../docs/qupath-plugin.md)).

Remove this folder before merging: release jars belong on the GitHub releases page,
not in the repository.
